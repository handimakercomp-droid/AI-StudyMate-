# AI StudyMate 🤖📚

## اسم المشروع
**AI StudyMate – المساعد الذكي لتنظيم المذاكرة**

## وصف المشروع

AI StudyMate هو تطبيق ويب يساعد الطلاب على تنظيم وإدارة عملية المذاكرة في مكان واحد، من خلال إدارة المواد الدراسية والمهام والامتحانات، بالإضافة إلى متابعة مستوى التقدم الدراسي.

يهدف المشروع إلى تحسين تجربة الطالب وتسهيل تنظيم وقته ومتابعة إنجازاته باستخدام واجهة بسيطة وحديثة، مع إضافة ميزة تعتمد على الذكاء الاصطناعي لتوليد أسئلة للمراجعة.

## أهم مميزات التطبيق

- 📚 إضافة وإدارة المواد الدراسية.
- ✅ إضافة المهام الدراسية وتحديد حالتها.
- 🗑️ حذف المهام والمواد والامتحانات.
- ⭐ تحديد أولوية المهام.
- 📝 إضافة الامتحانات ومواعيدها.
- 📊 عرض إحصائيات عن مستوى الإنجاز.
- 📈 متابعة نسبة التقدم في كل مادة.
- 🤖 توليد أسئلة للمراجعة باستخدام ميزة AI.
- 🌙 دعم الوضع الداكن Dark Mode.
- 💾 حفظ البيانات باستخدام LocalStorage.
- 📱 تصميم Responsive يعمل على الكمبيوتر والموبايل.
- 🎨 واجهة مستخدم حديثة وسهلة الاستخدام.
